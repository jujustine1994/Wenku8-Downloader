# Wenku8 Downloader

從 wenku8.net 輕小說網站批次下載整本書所有卷次，自動爬取目錄、逐卷下載並儲存為 TXT 檔。

## 主要功能

- **整套或單卷都能貼**：貼書籍目錄網址抓整套；貼 `?vid=` 或章節頁網址只抓那一卷。
  貼進去的當下就會顯示程式會怎麼處理（整套／單卷／認不出）
- **增量更新**：輸出資料夾會記一份 `.wenku8.json`（書號、來源網址、每卷的下載時間與
  完整性），按「更新」重抓目錄後只抓新卷與驗證沒過的卷，不重抓舊檔。舊資料夾第一次用
  會按檔名回推建紀錄，不會整套重抓
- **完整性驗證**：除了亂碼，也用目錄頁的章節標題當錨點偵測斷檔（HTTP 200 但內容不完整）
- **自動簡轉繁**：內文與檔名都轉（可在設定關閉）
- 下載完自動修復失敗／亂碼卷、可隨時跳過目前卷、正式卷與外傳卷各自編號

## 執行方式

雙擊 `Wenku8下載器啟動器.bat`，首次執行會自動安裝所需套件。

「設定」分頁提供「檢查更新」按鈕，可手動比對並一鍵安裝 GitHub 上游的最新程式碼，
不會自動觸發，安裝前會列出實際變更內容供確認。

## 系統需求

- Windows 10/11
- Python 3.10+（首次執行自動安裝）
- uv（首次執行自動安裝）
- 網路連線

## 技術棧

- 語言：Python 3.10+
- UI：tkinter（原生 ttk 主題；sv-ttk 已停用，見 CHANGELOG v13）
- 套件：curl_cffi（模擬 Chrome TLS 指紋繞過 Cloudflare）, beautifulsoup4, lxml, opencc-python-reimplemented（簡轉繁）
